# Inbox Zero: public auth without mesh oauth; Workload-local Redis

Inbox Zero lands as a Shardblade Workload at `inbox.adryan.me` using the upstream Helm chart (Pinned), Sphere for Postgres, BullMQ, Google/Gmail only, and deploy-locked LLMs via OpenRouter (`openrouter:deepseek/deepseek-v4-flash-latest`). We expose it on a public host with Inbox Zero’s own OAuth and an `AUTH_ALLOWED_EMAILS` allowlist — not mesh oauth2-proxy — because the app already gates on Google login and double-gating adds friction without replacing mailbox OAuth. Redis stays Workload-local (chart Redis + HTTP bridge) with extractable auth/prefix seams: the app requires Upstash-shaped Redis beyond queues, but a shared Redis platform is deferred until a second consumer appears rather than standing up one-tenant platform infra now.
